  Pod 1: api-deployment (API principal)
  ─────────────────────────────────────
  - Gerenciado pelo CI/CD
  - Auto-scale (1-10 replicas via HPA)
  - Atualiza quando há push no GitHub
  
  
  Pod 2: postgresql (Banco de Dados)
  ──────────────────────────────────
  - StatefulSet (dados persistentes)
  - ISOLADO do CI/CD (sempre rodando)
  - NÃO é recriado em deploys
  - 10Gi storage
  
  
  Pod 3: seq (Logs Centralizados)
  ───────────────────────────────
  - Deployment independente
  - ISOLADO do CI/CD (sempre rodando)
  - 5Gi storage
  - Recebe logs de todos os pods

 🔑 USUÁRIO E SENHA DO POSTGRESQL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Configurado em: charts/values.yaml
  
  postgresql:
    username: postgres
    password: postgres    ← TROCAR em produção!
    database: appdatabase
  
  
  Para criar secret com senha customizada:
  ─────────────────────────────────────────
  
  kubectl create secret generic postgresql-secret \
    --from-literal=POSTGRES_USER=seu_usuario \
    --from-literal=POSTGRES_PASSWORD=SuaSenhaSegura123! \
    --from-literal=POSTGRES_DB=appdatabase \
    -n dev
  
  
  O PostgreSQL usa este secret automaticamente!
